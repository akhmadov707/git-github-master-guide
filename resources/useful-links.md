# Foydali havolalar

Quyidagi manbalar Git, GitHub va terminalni o‘rganish uchun foydali.

1. [Git rasmiy sayti](https://git-scm.com/) — Git haqida ma’lumot va dasturni o‘rnatish.
2. [Pro Git kitobi](https://git-scm.com/book/en/v2) — Git bo‘yicha batafsil qo‘llanma.
3. [GitHub](https://github.com/) — repository yaratish va loyihalarni joylashtirish.
4. [GitHub Docs](https://docs.github.com/) — GitHub funksiyalarining rasmiy hujjatlari.
5. [GitHub Skills](https://skills.github.com/) — amaliy mashqlar orqali o‘rganish.
6. [Markdown Guide](https://www.markdownguide.org/) — Markdown yozish sintaksisi.
7. [Microsoft Learn: PowerShell](https://learn.microsoft.com/powershell/) — Windows PowerShell bo‘yicha hujjatlar.

## Xavfsizlik
- GitHub paroli va Personal Access Token’ni hech kimga yubormang.
- Tokenni kod yoki ochiq repository ichiga joylamang.
- Noma’lum buyruqlarni tushunmasdan ishga tushirmang.
